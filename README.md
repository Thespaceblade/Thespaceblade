# Jason Charwin

Data Science undergraduate at the University of North Carolina at Chapel Hill focused on applied machine learning, statistical modeling, and building end-to-end data systems that work under real-world constraints.

My work spans research-driven ML, analytics engineering, and full-stack data products, with applications in healthcare, genomics, and performance analytics. I care deeply about reproducibility, modeling assumptions, and turning high-dimensional data into decisions that hold up outside the notebook.
