# Hi, I'm Jason

I'm a Data Science undergraduate at the University of North Carolina at Chapel Hill, with a strong focus on statistics, computing, and applied machine learning.

I’m interested in building data-driven systems that actually hold up in the real world. That means thinking seriously about **modeling assumptions, data quality, interpretability, and impact**, not just performance metrics.

My academic and project work spans **machine learning, statistical modeling, data engineering, and software development**, with applications in healthcare analytics, social impact research, and systems-level data problems. I’ve worked on projects ranging from predictive modeling and algorithm audits to full-stack data products and backend systems.

Outside of coursework, I actively build tools and applications to sharpen my engineering skills, including analytics dashboards, ML pipelines, web apps, and infrastructure for self-hosted services. I care a lot about clean abstractions, reproducible workflows, and understanding systems end-to-end.

Currently focused on: applied machine learning, statistical inference, backend systems, and turning messy real-world data into reliable insights.
